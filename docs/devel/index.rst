Code changes
============

1. Please keep commits simple and atomic
2. Please test all code changes
3. Please follow our code style guidelines

All changes must be made through *pull requests*!


Adding new functionality
=========================
If you're adding a new script or module, please check
:doc:`writing-code`.


Testing
=======
When adding or changing core modules, please write unit tests!
