===================
NVA/Cristin/Frida
===================

Cristin is now known as Cris/NVA (Nasjonalt vitenarkiv), and is a national
research information repository.

The archive collects and openly distributes publications and research from
Norwegian universities, colleges, and institutes.


Cristin
========
Cristin (Current research information system in Norway) is a research
publication register and publishing system.

More info:

- `The Cris/NVA service <https://sikt.no/tiltak/cris-nva-prosjektet>`_
- `Cristin XML file integration
  <https://www.cristin.no/ressurser/dokumentasjon/institusjonsdata/>`_


Cerebrum
=========
Most institutions now rely on an external integration with Cris/NVA, using
`Cristin MS <https://github.uio.no/ITI-INT-AS/cristin-ms/>`_.

For now, a legacy XML export still exists in Cerebrum.  The export consists of
two parts:

1. Cerebrum support for storing detailed employment data (:doc:`mod_employment`)

2. A Cristin XML export script (:doc:`cristin-export`)
